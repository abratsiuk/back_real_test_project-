Александр Петрович, всё ок, кроме предупреждения про `PriceUsd`. Исправляем и едем дальше.

1. **Задайте точность** (любой из вариантов).

* В `Models/Book.cs` (над свойством):

```csharp
using System.ComponentModel.DataAnnotations.Schema; // наверху файла

[Precision(10, 2)]                 // ← ДОБАВЬТЕ ЭТУ СТРОКУ
public decimal PriceUsd { get; set; }
```

или

```csharp
[Column(TypeName = "decimal(10,2)")]
public decimal PriceUsd { get; set; }
```

* Либо через Fluent в `Data/AppDbContext.cs`, в `OnModelCreating` **после** `HasKey`:

```csharp
b.Entity<Book>().Property(x => x.PriceUsd).HasPrecision(10, 2);
```

2. **Пересоберите миграцию и обновите БД**:

```bash
dotnet ef migrations add SetPricePrecision
dotnet ef database update
```

(Опционально обновить инструменты: `dotnet tool update --global dotnet-ef`.)

Готово. Дальше дам короткий `BooksController` (GET page + POST create), по команде.
